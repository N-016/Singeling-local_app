# Cassette (thema)

- Stijl: jaren 80 in pastel (cassettebandje, kubuspuzzel, Memphis-vormen).
- Kleurenpalet en achtergronden (`cassette-light.svg`, `cassette-dark.svg`): zelf gemaakt voor de Singeling App.
- Lettertypes (Latijnse tekens, woff2 via Google Fonts), SIL Open Font License 1.1:
  - tekst: [Fredoka](https://github.com/hafontia/Fredoka-One) (zie `OFL-Fredoka.txt`);
  - koppen: [Righteous](https://fonts.google.com/specimen/Righteous) (zie `OFL-Righteous.txt`).
